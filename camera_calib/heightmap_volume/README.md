# 从归档扫描点云估计实体体积

2026-11-25。输入取自 `standard_scan/runs/baseline_20261118` 的六组原始重建。单位为 mm、mm²、mm³。输出：[体积对照及行程表](runs/baseline_20261125/report.md) · [各阶段计时 CSV](runs/baseline_20261125/volumes.csv) · [高度图及误差图](runs/baseline_20261125/diagnostics/)。

## 运行

从本目录执行，依赖 NumPy、SciPy、Matplotlib。

```powershell
python -m unittest test_heightmap -v
python run_volume.py --pitch 0.5
```

默认新建时间戳目录；可指定 `--source` 和尚不存在的 `--out`。独立测量接口为 `estimator.measure(xyz_mm, pitch=0.5, scan_step=2.)`，只接收世界系点云和采样参数。输出网格为 [Y,X]，保存格心坐标和参考平面系数。

## 扫描审计

先按每帧归档位姿、像素和内参反查世界坐标：相机向下，世界 Z 向上；检查变换回相机系后的投影及光平面残差。读取渲染日志仅用于审计物理步长。理想组沿 X 正向走 62 步，每步 2 mm、行程 124 mm；扰动组实步长、路径长度和逐帧位置保存在 [archive_audit.json](runs/baseline_20261125/diagnostics/archive_audit.json)。表中的 XY 是整幅点云范围；JSON 的 `top_xy_mm` 单列顶面范围。

在理论顶面水平投影上以 0.5 mm 格心核查：六组的行程包络、最近扫描位置的相机画幅及激光扇面覆盖均为 100%，首末帧均无物面点。无明显行程截断，沿用原扫描配置。审计同时计算正确高度层的直接命中率及邻域支持率（水平距离 ≤1.5 mm，高度差 ≤1 mm）；前者约 24%～25%，后者为 99.63%～100%。该面积口径针对高度积分所需的上表面投影，未计入竖直侧壁。真实掩膜仅出现在审计和评价端。

## 积分及缺测处理

1. 从低分位台面点开始，按残差重选支持点，拟合 `z=ax+by+c`。使用相对台面的**竖直高度**乘水平面积。底面平放是本阶段的物理假设。
2. 高于台面 1 mm 的点建立自动占据区域；用沿行程和横向的局部采样尺度生成轮廓。内部包围区域列为待判定，实测台面格从足迹中排除。外部无台面回波的格仍可由 `ground` 掩膜区别。
3. 格内样本取中位数。局部三角形最长边须 ≤1.45 倍步长、顶点高差 ≤1.6 mm；邻近台面处禁用三角插值。轮廓边带和深度突变处仅允许受距离及同层邻点约束的单侧估计；两层归属不清或间隔过大保留空格。0.5 mm 是输出格距，原归档行程采样间隔为 2 mm。
4. `grid.npz` 的 `status`：0 自动足迹外，1 直接命中，2 局部三角插值，3 足迹内缺测，4 局部单侧估计。2 和 4 独立计数。3 保留 NaN、不参与积分；体积是有效格高度和乘格面积。漏格会减少积分，外轮廓扩张可增大积分，净偏差可正可负。
5. 正式报告的分母为**自动足迹面积**；有效占比 = (1、2、4 的格数之和)/足迹格数。真实投影上的直接率另列在审计表；轮廓外扩、内缩及有效格高差分解保存在 [reference_comparison.json](runs/baseline_20261125/diagnostics/reference_comparison.json)。高度误差图显示与真值重合且有积分值的格，色标在 ±1 mm 饱和；配套状态图标出缺口。未使用 oracle 掩膜求正式体积。

## 结果如何解读

- **A 圆柱**：理想组轮廓多纳入 143.25 mm²、漏掉 6.00 mm²。圆周半步带的面积偏差乘上约 50 mm 高度，主导了 +1.83% 的体积偏差。
- **B 组合件**：理想组槽底及孔底的中位相对高度均为 34.88 mm，理论为 35 mm；在真实开口内分别有 79.88% 和 86.87% 面积参与积分。交界处保留缺口，整体低估 1.37%。扰动组两处有效率升至 89.00%、90.51%，漏项与轮廓外扩部分抵消，整体低估 0.24%。
- **C 自由曲面**：理想组在共同有效区的绝对高度误差 P95 为 0.249 mm；扰动组为 0.321 mm。理想组有效区高度平均偏低 0.117 mm，轮廓外多积分约 5381 mm³，最终体积偏高 0.95%。
- **评分**：依据 2026-11-17 区赛参考细则赛题 2（PDF 第 12 页），测量体积先保留一位小数，各类绝对相对误差按 0.2/0.3/0.5 求和。理想、扰动组原始 P 分别为 0.012540、0.008014，按规则均为 0.01。计时覆盖点云读取至积分，不含成像和绘图。
