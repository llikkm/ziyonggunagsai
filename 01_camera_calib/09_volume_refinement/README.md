# 09 固定 PLY 上的轮廓定位与保边高度积分

输入是 06 模块归档的六个 `reconstruction/cloud.ply`。每组只读一次，同一坐标数组先后送入 07 基线和本候选算法。积分格距 0.5 mm、名义行程步长 2 mm。未重新扫描，未改帧率。本候选适用于沿 X 正向扫描、每帧按相机行顺序导出的点云；不适用于重新打乱点序的通用 PLY。

## 方法

- 从世界坐标 Y 的回跳恢复扫描线，取相对拟合台面的顶面端点。按条纹端点沿扫描方向连接轮廓，并按采样间距给两端各半格支持，替代原先向各方向扩张的轮廓带。竖直切片假设外轮廓单区间。
- 圆柱候选同时检查顶面分位高度跨度和自由圆拟合的径向残差。只对平顶且轮廓吻合的对象使用拟合圆；圆心、半径均从测点估计。圆内仍走高度积分，未观测格受同样的距离和邻点支持约束。
- 对候选边界内的缺格，检查十二个邻点的高度分布。在槽口或孔口遇到明显跳变时分层，只对最近侧有足够支持且归属清楚的格做同层加权。台面测点更近或支持不足时保留 NaN。新增状态 5 表示局部估计；状态 1 仍表示直接命中。原有点和基线网格保留。
- 所有类别使用同一入口 `refine(points, baseline)`。仅在 `compare.py` 的评价步骤中按类别调用理论表面和体积。未针对 C 添加常量高度补偿。

- A 理想组，原诊断仅套拟合圆得到 249155.9 mm³。本次在近邻条件满足的 116 格恢复局部高度，得到 250601.0 mm³。共同有效区平均高度仍低约 0.169 mm。
- B 理想组 544 格在检测到深度突变时按层估计，扰动组为 273 格。相应槽底和孔底继续使用相对台面的测量高度。
- C 理想组足迹面积 10136 → 10050 mm²，扰动组 10117 → 10024.5 mm²。共同有效区平均高度偏差分别为 −0.117、−0.097 mm，轮廓修正主导了本次改善。下一步可用独立平面测量检验高度偏差来源。
