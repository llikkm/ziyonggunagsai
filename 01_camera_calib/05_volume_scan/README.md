## 1. 物体、场景和单位

世界系：X 向右（物体长 100 mm），Y 向里（宽 80 mm），Z 向上（高 50 mm）；单位 mm，体积 cm³。相机系：X 右、Y 下、Z 前。

| 物体 | 几何 | 真实体积 |
| --- | --- | ---: |
| A | 100×80×50 mm 长方体，底面 Z=0 | 400 cm³ |
| B | 长方体顶部挖 20×20×10 mm 盲槽，槽口 X 40..60 / Y 30..50，槽底 Z=40 | 396 cm³ |
| C | 长方体侧面挖 20×20 mm 沿 Y 贯穿的方孔，孔 X 40..60 / Z 20..40 | 368 cm³ |

C 的 32 cm³ 是孔的体积，正好等于 20×20×80 mm 的空腔。高度图只在 (X,Y) 上存一个高度，顶部扫描看到的是完整顶面 400，孔被“盖住”了。

扫描机构：

```text
P_w = R_i P_c + t_i
R_i = diag(1, -1, -1)                 # 相机系到世界系
t_i = (x_i, 40, 300) mm               # 相机中心；x_i = -55..55, step 1 mm
```

相机和激光器刚性连接；物体固定；`x_i` 是机构位置。激光平面在相机系：

```text
n_c = [1, 0, 0.2], d_c = -100        # n·X + d = 0
laser source_c = [100, 0, 0]          # 高源
world plane: n_w = R_i n_c, d_w = d_c - n_w·t_i
```

条纹落在物体顶面的世界 X 约为 `50 + x_i`，所以 111 帧覆盖 X=-5..105，足够扫过 0..100 的物体。默认相机内参来自 `../out/calib.json`（fx≈989.77, fy≈991.66, 1280×720, 有畸变）；`--synthetic-camera` 可用 fx=fy=806 的无畸变相机快速跑通。

## 2. 真正的正向仿真与数据隔离

本模块的“真值”只用于三处：生成可见表面/渲染图像、生成候选交线、最后算体积误差。反算函数拿不到真值表面。

### 2.1 单帧

1. 物体每个面是一个矩形 `Quad`（origin, e1, e2, length1, length2, outward normal）。C 的侧孔、B 的槽底/槽壁都是真实四边形。
2. 激光平面与每个四边形求交，得到一条线段；用 `plane_quad_segment()` 做三平面/边界的线段裁剪。
3. 逐点做可见性：
   - 激光入射面：`normal·(L-P) > 0`；
   - 相机可见面：`normal·(C-P) > 0`；
   - 相机遮挡：线段 `P→C` 是否被其他面片挡住；
   - 激光阴影：线段 `P→L` 是否被其他面片挡住；
   - 视场：投影 `uv` 是否落在 1280×720 内。
4. 可见点按连续段分组，**每段单独渲染**再取 max，避免阴影两侧被连成一条假条纹。
5. 渲染为局部高斯条纹；`extract_laser_centers(axis="row")` 做行方向亚像素中心提取（条纹近似竖直）。
6. 只把 `uv`（像素）交给反算；反算用 `K/dist + 激光平面` 得到相机系点，再按 `R_i,t_i` 变到世界系。

### 2.2 为什么用“已知足迹 D”

高度图积分需要物体在基准面上的足迹 D：

```text
V = ∬_D h(x,y) dx dy
```

本实验的 A/B/C 是已知尺寸的规则物体，**D 取已知的 100×80 mm 投影**。这不是把真值点云传给反算：D 是物体 CAD/设计尺寸，反算仍然只用像素、K/dist、平面和位姿。通用未知物体需要分割/凸包/多视角来得到 D，边界缺失会直接变成体积误差。

### 2.3 基准面估计

- 用世界 Z 最低的 15% 点寻找初始平面，再从完整点云分离地面支持点，以 MAD 门限和 SVD 细化；
- 法向翻到 +Z 侧；基准面 `h = n·P + d`；
- 基准面由重建点云估计，用于高度和体积计算；像素反算不接收真实基准面；
- 低激光源会遮住地面基准条纹，此时 RANSAC 会失去基准；shadow 场景明确改用基线基准面，只用于隔离槽底阴影，不能当成“低源下仍能估基准”的结论。

### 2.4 高度图与体积

- 只取基准面以上 1 mm 的点；
- 格内取**最高可见表面**（这是高度图能处理凹槽、但不能处理悬空/内部空腔的关键）；
- 0.5 mm 网格；空格用邻域均值最多填 3 次，只填扫描线之间的窄缝，不做大范围外推；
- `V = Σ h_ij · du · dv`；覆盖率 = 有观测的格 / D 的总格数；
- 覆盖率低说明数据缺失；体积不一定立刻错，因为有限填充可能把窄缝补上，但 FOV 这类大块缺失会保留为空并明显欠估。

## 3. 误差是怎么加进去的

为了把各类误差分开，基线只渲染一次，后续误差场景复用基线像素/位姿：

| 场景 | 注入位置 | 说明 |
| --- | --- | --- |
| `pixel` | 提取后的 `uv` 加高斯噪声 | 0.15/0.5/1.0 px；不重新渲染 |
| `motion` | 世界变换 `t_i` 加高斯误差 | σ=0.1/0.5/1.0 mm；图像仍按标称位姿，等价于编码器/机构读数误差 |
| `plane` | 反算平面改成 `n_z+0.002/+0.005` | 渲染仍用真平面；模拟平面标定参数误差 |
| `omission` | 随机丢帧 | 10%/25%；基线和像素复用 |
| `fov` | 帧掩码 FOV 35 mm | 物体两端 15 mm 没扫到 |
| `shadow` | 低激光源重新渲染 | `source_c=[56,0,220]`；槽底不变，地面基准被遮 |

这是“误差隔离”的仿真：motion/plane 不重新渲染，避免把图像变化和坐标误差混在一起；真实硬件上两者会耦合，后续应做联合仿真/实测。

## 5. 方法限制

1. **隐藏空腔/侧孔**：C 的 32 cm³ 在顶部高度图中不存在；高度图方法必错。需要多视角、侧面扫描、或者封闭网格/占据栅格。
2. **悬空/多层**：高度图每个 (x,y) 仅一个高度；上下两层会丢掉下面一层。本实验用侧孔代表“被遮挡的内部体积”，悬空同理。
3. **遮挡/阴影**：B 槽底只有 80% 可见；槽壁边缘的 20% 会变成体积偏差。低源还会遮住地面基准。
4. **视场**：|x|≤35 mm 时两端 15 mm 没数据；高度图 D 上留空，体积欠估 106 cm³；覆盖率是最直接的告警。
5. **单峰行提取**：现有 `extract_laser_centers` 每行只取一个中心；当地面基准条纹和物体顶面条纹落在同一行不同 u 时，会二选一，造成点云覆盖下降/边缘缺失。基线 57% 覆盖率就包含这个因素。多回波/多峰提取是下一步。
6. **已知足迹 D**：本实验用已知 100×80；未知物体要用分割/凸包，边界和缺失会影响体积。
7. **误差注入是分离的**：motion/plane 不重新渲染，pixel 只加中心噪声；真实硬件上图像变化和坐标误差会耦合。
8. **仿真理想化**：条纹用高斯模型，没有散斑、景深、过曝、二次反射、卷帘快门；相机畸变用现有模型；激光平面是理想平面。
9. **真实标定板 19 mm**：本仿真按 20 mm 设计值；实物打印板实测 19 mm。真实标定/平面标定必须传 `--square 19`，否则尺度整体偏约 5%。本模块不解决这个系统尺度问题。
10. **低源 shadow**：使用基线基准面；不能据此认为低源下基准面仍可估。

## 8. 与项目其他模块的接口

- 相机：`laser_lib.CameraModel.from_calib_json("../out/calib.json")`；本模块的 `ScanSetup.camera` 接受任意 `CameraModel`。
- 激光平面：`ScanSetup.laser_plane_c` 是相机系 `LaserPlane`。本仿真用理想平面；真实标定后把 `04_laser_plane_calib/out/results/laser_plane.json` 的 `n,d` 传进来即可（注意它是在相机系，且真实板 19 mm）。
- 机构：`ScanSetup.pose(i)` 返回 `R_i,t_i`；真实设备把编码器/运动平台读数填进 `t_i`，`R_i` 按实际安装旋转填入。本模块的 `P_w=R_i P_c+t_i` 和 `reconstruct_scan()` 不需要改。
- 像素：真实相机用 `extract_laser_centers` 得到的 `uv` 填 `ScanFrame.uv`；`simulate_scan` 只是仿真入口。
- 数据隔离：不要把 `ScanObject.quads` 或真实点云传进 `reconstruct_scan`；反算只应接收 `uv/K/dist/plane/pose`。
