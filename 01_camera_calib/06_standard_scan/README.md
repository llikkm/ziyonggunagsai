## 2. 运行（PowerShell）

从项目根目录执行；本机使用 Python 3.12、Open3D 0.19、NumPy、OpenCV 和 Matplotlib，扫描不需要相机或联网。

```powershell
cd 01_camera_calib/06_standard_scan
python -m unittest test_standard -v
python simulate.py --seed 42
python verify_run.py runs/baseline_20261118
python replay.py runs/baseline_20261118/B_ideal/measurements runs/my_B_replay
```

默认扫描输出到 `runs/<时间戳>/`；用 `--out` 可指定新路径。已有输出目录会被拒绝。`verify_run.py` 在临时目录只复制测量输入，并与已存逐帧像素、偏移索引、三维坐标及 PLY 逐点核对。

## 3. 光路与数据接口

世界 Z 向上，相机 X 向右、Y 向下、Z 向前。相机朝下，名义高度 210 mm；激光源位于相机左侧 62 mm。每帧向扇面内发射 1201 条射线，首交产生照明点，包含物体和台面；从相机向各点再次求首交，超过 0.002 mm 的前景遮挡剔除。投影保留 320×240 像素画幅内的条纹，亚像素分配亮度并做高斯展宽。理想内参无畸变，扫描步长 2 mm。

- `models/`：三个三角网格 PLY 和预览 PNG。模型只在渲染与验收阶段使用。
- `<类别>_<模式>/measurements/`：63 张原始灰度 PNG 和 `config.json`（逐帧名义平移、固定旋转、相机参数及相机系平面）。`replay.py` 仅读取此目录，逐行调用 `extract_laser_centers`，再调用 `reconstruct`；世界坐标为 `P_camera @ R.T + t`。
- `render_log.json`：逐帧真实位置和各级可见性计数。`jitter` 各帧加入独立高斯平移，XYZ 标准差分别为 0.25/0.12/0.10 mm，整套测量头一起移动；记录种子，不扰动测量端名义读数。
- `reconstruction/`：`cloud.ply` 含台面及可见物面；`points.npz` 保存 `xyz_mm`、`uv` 和按帧划分的 `offsets`。原帧、空白区域与遮挡缺口保留。

## 4. 验收与交接

[六组基线结果](runs/baseline_20261118/summary.json)：共 378 帧。理想 B 的两个特征中心半径 7 mm 内各测得 156 个底面点，中位高度均为 35.000 mm。C 内部区域 `|x|,|y|<45 mm` 的绝对高度误差 P95：理想 0.153 mm，平移扰动 0.305 mm。单峰提取每行至多保留一个中心，台阶边界可能漏点。当前验收止于融合点云；下一阶段应从点云估计台面并自动分割，单独报告覆盖率和体积误差。

后续开发沿用[项目维护规则](../PROJECT_README.md#handoff)。修改模型先跑几何测试，修改成像需分别检查激光方向与相机方向的遮挡，修改重建需重放六组测量输入。新实验另存目录，并在项目变更记录登记结果和待办。
